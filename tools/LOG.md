# Tool log

One line per change to the build tools: what slipped through, what catches it now.

- 2026-10-08 · initial gate: verify, smoke, badges-check, i18n-check, self.check.
- 2026-10-08 · smoke ran as soon as astro.config.mjs existed and crashed on the bare scaffold; it now waits for the API it exercises (src/pages/api/questions.ts).
- 2026-10-08 · a commit went in with verify red because a shell pipe hid the exit code; a pre-commit hook now runs verify on every commit. self.check's good badge fixture also stopped depending on the active locale, and a fixture without names now proves the locale rule.
- 2026-10-08 · astro build does not type-check, so a TS error in src/lib would have shipped green; verify gained a 'types' step (tsc --noEmit) and self.check proves tsc rejects a type error.
- 2026-10-08 · verify never ran the client JavaScript, and a favicon 404 on every page went unnoticed until checked by hand in Chrome; a 'ui' step now drives the pages in headless Chrome over CDP (tools/lib/browser.mjs, no new dependency) and fails on script errors and failed requests. Its first version listened to Runtime only and missed the 404 too; it now also listens to the Log domain, and self.check proves both are caught. smoke and ui share tools/lib/server.mjs.
- 2026-10-08 · the setup-skill eval on a fresh checkout failed at 'types' (no .astro/types.d.ts, so import.meta.glob was unknown); the step now runs astro sync before tsc. assign.check also covered only the active theme, so a broken inactive theme could ship; it now checks every theme.
- 2026-10-08 · badges-check demanded active-locale names in every theme, so the French setup eval had to translate the unused animals theme; it now requires them only in the active theme (or a theme checked alone) and warns for the rest. self.check proves an unnamed inactive theme passes.
- 2026-10-08 · the reviewer agent found what verify could not see: sequential ids leaking arrival order, a Google Fonts import leaking participants' IPs, no length or body-size limit tested, a release delay only ever tested at 0. smoke now asserts non-sequential ids, the exact questions columns, 400/413 for oversized input, that a 60 s delay holds a question back, and no server secret in dist/client; ui fails on any third-party request and posts a question with markup that must render as text; boundaries-check keeps badge ids in themes and AI SDKs in judges. Each new rule was mutation-tested (sequential ids and the font import put back → red) or has a self.check fixture.
- 2026-10-08 · i18n-check only saw t() keys, so a literal string typed into a page (like the old '???') passed; it now flags letters in .astro markup, in HTML built by client scripts and in user-facing attributes. Symbols and emoji stay allowed. self.check has four fixtures; mutation-tested on index.astro.
